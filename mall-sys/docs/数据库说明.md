# 数据库说明（mall-sys）

## 一、连接信息

| 项 | 值 |
|---|---|
| 主机 | `127.0.0.1:3306` |
| 库名 | `mall-sys` |
| 账号 | `root / 123456` |
| 驱动 | `com.mysql.cj.jdbc.Driver`（8.0.28，见 `pom.xml`） |
| JDBC URL | `jdbc:mysql://127.0.0.1:3306/mall-sys?useUnicode=true&characterEncoding=UTF-8&useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Shanghai` |

> 驱动原来是 5.1.47（MySQL 5.x 时代的），而库是 MySQL 8.0，已换成 8.x。
> 换驱动后 URL 必须带 `serverTimezone`，否则会报时区错误。

## 二、库名带连字符 —— 必须写反引号 ⚠

库名 `mall-sys` 中间是连字符，不是下划线。**不加反引号会被当成减号解析而报错**：

```sql
-- 错：会被解析成 mall 减 sys
SELECT * FROM mall-sys.tbl_user;

-- 对
SELECT * FROM `mall-sys`.`tbl_user`;
USE `mall-sys`;
```

**为什么不直接把库名改成 `mall_sys`**：改名要动配置、动所有 SQL、还要迁移数据，
收益（少敲两个反引号）远小于风险。所以保留原名，靠规范约束：
本文件配套的 `schema.sql` 里所有库名/表名/列名**已全部带反引号**，照抄即可。

## 三、建表脚本

`docs/schema.sql` —— 从现有库导出的完整 DDL（47 张表，含注释与字符集）。

```bash
# 重新导出
mysqldump -uroot -p123456 --no-data --skip-add-drop-table "mall-sys" > docs/schema.sql

# 在新机器上重建
mysql -uroot -p -e "CREATE DATABASE \`mall-sys\` DEFAULT CHARSET utf8mb4;"
mysql -uroot -p "mall-sys" < docs/schema.sql
```

## 六、密码存储

`tbl_user.password` 与 `tbl_member.password` 存的是
`SHA2(CONCAT('mall-sys-pwd-pepper-2026::', 明文), 256)`，不是明文。

配套逻辑在 `com.gec.util.PasswordUtil`；迁移脚本 `tools/migrate_password.py`（可重复执行，
已哈希的会跳过）。测试 `PasswordUtilTest` 锁定了哈希值，改 pepper 会直接测试失败。
